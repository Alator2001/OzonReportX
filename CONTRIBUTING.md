# Как помочь OzonReportX

Спасибо, что заглянули! Помочь можно и без программирования.

## Сообщить об ошибке или предложить идею

[Создайте issue](https://github.com/Alator2001/OzonReportX/issues/new/choose) по шаблону. Для ошибки пригодятся:
версия программы («Настройки» → «Проверить обновления»), система (Windows / macOS), что делали и что произошло.
Журнал последнего запуска лежит в папке с данными: `.cache/logs/`.

**Не публикуйте** ключи API, файл `.env`, архив переноса и отчёты с реальными цифрами, если не хотите их раскрывать.

## Изменения в коде

1. Сделайте форк и ветку от `main`.
2. Подготовьте окружение (Python 3.14):
   ```bash
   python3.14 -m venv .venv
   .venv/bin/pip install -r config/requirements.lock.txt
   ```
3. Запуск: `.venv/bin/python app_flet.py`. Тесты (должны проходить):
   ```bash
   .venv/bin/python -m unittest discover -s tests
   ```
4. Откройте pull request с описанием, что и зачем изменено.

Как устроена программа, где какие расчёты и какие ограничения у API Ozon — в
[документации для разработчиков](docs/dev/README.md). Изменили поведение — обновите и её.

Отправляя изменения, вы соглашаетесь, что они распространяются по лицензии проекта — [GNU GPL v3](LICENSE).
