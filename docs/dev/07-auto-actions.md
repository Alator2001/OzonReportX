# 07. Автодобавление в акции и учёт минимальной цены

Панель на вкладке «Акции». Код: `scripts/auto_actions.py`, интерфейс — `auto_load`, `render_auto_panel`,
`auto_confirm` в `app_flet.py` (около строки 6880).

## Два механизма Ozon

| | Автодобавление | Учёт минимальной цены |
|---|---|---|
| Что делает Ozon | В даты автодобавления акции (`auto_add_dates`) сам включает товар в акцию по цене, которую выберет сам | При автодобавлении не опускает цену товара ниже его `min_price` |
| Флаг | `price.auto_add_to_ozon_actions_list_enabled` в `/v5/product/info/prices` (`ENABLED`/`DISABLED` или bool) | `min_price_for_auto_actions_enabled` в `/v1/product/action/timer/status` |
| Срок | Нет. Но Ozon иногда включает автодобавление обратно сам | Есть: `expired_at`. После него учёт сбрасывается |
| Как менять | `/v1/product/import/prices` с `auto_add_to_ozon_actions_list_enabled` | Включить — `/v1/product/import/prices` с `min_price_for_auto_actions_enabled: true`; продлить — `/v1/product/action/timer/update` (цены не меняются, переносится дата сброса) |

Минимальную цену в Ozon (`min_price`) задаёт «Обновить минимальные цены в Ozon» (см. [05](05-pricing.md#минимальная-цена-в-ozon-update_pricespy)).
Без неё учёт минимальной цены включить нельзя — программа сразу помечает такие товары ошибкой.

Флаг «автоприменение акций» (`price.auto_action_enabled`) программа не использует: Ozon пометил его
устаревшим 11 сентября 2026, колонка убрана из таблицы.

## Чтение состояния — `load_state(root)`

1. `load_prices()` — **все товары магазина** (`visibility: ALL`, страницы по 1000), не только из `costs.xlsx`.
2. `load_timers(product_ids)` — таймеры пачками по 100.
3. `build_rows` — строка на товар: цена, старая цена, `min_price`, автодобавление, учёт минимальной цены,
   дата окончания и сколько часов осталось, дата последнего изменения автодобавления программой
   и **`reverted_by_ozon`** — программа выключала автодобавление, а Ozon сейчас показывает его включённым.

Фильтры панели: все, «автодобавление включено», «таймер истекает» (≤ 72 часов, `AUTO_SOON_HOURS`),
«учёт минимальной цены выключен».

## Журнал

`actions history/auto_actions_log.jsonl` — по строке JSON на каждый товар каждого изменения:
`{at, action, product_id, offer_id, confirmed, expires_at, error}`. Журнал нужен, потому что у автодобавления
нет срока и истории в Ozon: только так видно, что Ozon вернул флаг сам. `last_auto_add_change` берёт последнее
**подтверждённое** изменение по товару. Журнал не переносится `transfer_data.py` (см. [99](99-known-issues.md)).

## Изменение — `apply_change(root, action, rows)`

`action`: `auto_add_off`, `auto_add_on`, `min_price_on`, `timer_update`. Запускается из панели после диалога
с объяснением действия и под `job_lock`.

1. Отправка. `_import_prices` шлёт только изменяемый признак (`offer_id`, `product_id` и флаг).
   Если Ozon отклонил товар с ошибкой, где упоминается цена (метод требует цены в запросе), запрос для таких
   товаров повторяется **с текущими ценами** (`price`, `old_price`, `min_price` из только что прочитанного
   состояния; `old_price` по умолчанию `"0"`) — те же значения, ничего не меняется.
2. Пауза 2 секунды: Ozon применяет изменения не мгновенно.
3. Перечитывание состояния и проверка по факту:
   `auto_add_off` → флаг выключен; `auto_add_on` → включён; `min_price_on` → учёт включён;
   `timer_update` → дата окончания появилась и изменилась.
4. Запись журнала и итог «<действие>: N из M (проверено по данным Ozon). Не применилось: K».

`_post` делает до 3 попыток при 5xx, 429 и обрывах связи, после каждой неудачной ждёт 3, 6 и 9 секунд
(пауза есть и после последней, перед ошибкой), затем `AutoActionsError` «Ozon временно не отвечает».
Другие 4xx — сразу `AutoActionsError` с текстом Ozon.

## Связь с акциями

- План «Добавить выгодные» предупреждает о кандидатах, которых Ozon может добавить сам по цене ниже минимальной
  (`watch`, только для сведения). Автодобавление он не выключает: Ozon добавляет товар, пока лимит акции не ниже
  минимальной цены, записанной в Ozon, — достаточно отправить туда свои минимальные цены. Выключить автодобавление
  можно в разделе «Автодобавление».
- Вывод товара из бустинга ценой ([06](06-promotions.md)) не мешает Ozon снова добавить его в следующую дату
  автодобавления, если оно включено. Устойчивый вывод — вывести и выключить автодобавление.
